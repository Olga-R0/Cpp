## Описание

Этот проект создан для систематической отработки навыков программирования на языке C++. Он включает в себя набор задач разной сложности — от базовых упражнений до полноценных приложений.

Цель проекта:
* закрепить синтаксис C++;
* освоить работу с основными библиотеками и структурами данных;
* отработать принципы ООП в C++;
* научиться писать чистый, эффективный и безопасный код;
* получить опыт работы с инструментами разработки на C++.
